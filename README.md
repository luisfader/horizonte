Песни Оксаны из романа-мюзикла **«Сияющий горизонт»** Роберта Фадера.

> После ядерной катастрофы мир замолчал. Оксана живёт в бункере и поёт для бетонных стен, покрытых нотами мужа.

Статический сайт для GitHub Pages: пока музыка молчит, падает пепел; когда звучит песня, идёт дождь и разгорается горизонт.

## Структура

```
index.html               страница с плеером
assets/js/canzoni.js     список песен (название, сцена, глава, длительность)
assets/js/app.js         плеер и тексты
assets/css/style.css     оформление
audio/                   mp3
testi/                   тексты песен, по одному .md на песню
```

## Как добавить песню

1. Положить mp3 в `audio/` с именем `NN-nazvanie.mp3`.
2. Создать `testi/NN-nazvanie.md` с текстом.
3. Добавить запись в `assets/js/canzoni.js` с тем же `id`.

## Формат текстов

Первая строка `# Название`, дальше куплеты через пустую строку. Куплет, который начинается со строки `[Припев]`, показывается как припев.
